EXTREME AI VOICE TYPER v3.7
Developer: Anurag Anant
═══════════════════════════════════════════════════════
What's new in Extreme AI Voice Typer 3.7? This is a minor update focused on making the setup process simpler.
═══════════════════════════════════════════════════════
✨ NEW FEATURES
───────────────────────────────────────────────────────
1. SIMPLIFIED API KEY SETUP.
◦ The separate "Manage API Keys" dialog has been removed. Now, right below "Select AI Provider" in AI Settings, you'll find a single API key field that automatically shows the key for the provider you've selected. Choose Gemini, and it asks only for your Gemini key. Choose Groq, and it asks only for your Groq key — no more unnecessary empty fields for providers you're not using.

2. TEST API KEY BUTTON.
◦ Right next to the new API key field, a "Test API Key" button lets you instantly check whether your key is working, without having to open any separate screen.

3. FIRST-TIME SETUP MADE EASIER.
◦ New users will now see the same simplified experience the very first time they use the app — pick your AI provider first, then enter just that one key, or turn on Use Default API Key to skip this step entirely.
───────────────────────────────────────────────────────
🛠️ IMPROVEMENTS
───────────────────────────────────────────────────────
• Mistral has been removed as an AI provider to keep the setup process short and focused. Gemini and Groq continue to be fully supported.

• This update directly addresses feedback from several users who found the earlier setup confusing, since it previously asked for API keys of AI providers they never intended to use.
