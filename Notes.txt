🎉 What's New in Extreme AI Voice Typer Version 5.1 Final

This update gives you a smarter way to fix misheard words, brings back a button many of you asked for, and makes Direct AI Voice Dictation more reliable.

✨ New Features:

1. Teach Correction (Experimental): Did the AI write a name or a word wrong? Now you can fix it right away. Open the "What do you want to do?" menu and tap "Teach Correction (Experimental)", or choose it as your Extension Startup Action. Your last dictated text opens in a correction screen. Correct the wrong word, press "Save Correction", and the extension replaces the wrong word with the correct one in your text box.

2. Easy Editing with Split Options: In the Teach Correction screen you can choose how the text is shown. "Custom" is selected by default and shows the whole text in one box, exactly as it is. Choose "Words", "Sentences" or "Characters" to split the text into a list. Then tap the part you want and edit only that part. This makes it much easier to fix a single word inside a long text.

3. Auto-Add to Word Dictionary: A new switch in the Teach Correction screen, "Automatically add corrected words to Word Dictionary", is ON by default. When it is ON, every word you correct is also saved in your Word Dictionary, so the extension writes it correctly next time without any extra work. Turn it OFF for text correction only: the wrong word is corrected in your text box, but nothing is saved in the Word Dictionary.

4. Get API Key Button Is Back: The "Get API Key" button has been added again in AI Settings for Gemini, Groq and OpenRouter. Tap it to open the website where you can create your API key.

🛠️ Bug Fixes:

5. No More Overlapping Recordings in Direct AI Voice Dictation: Earlier, you could start a new recording while the previous one was still being processed. This is fixed. If you try now, the extension says "Still processing, please wait." and you can record again only after the previous recording is finished. "Process last recording" is protected in the same way.

6. Other Fixes: We fixed some more minor bugs and made small improvements for a smoother and more stable experience.
