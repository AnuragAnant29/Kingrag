What's new in Extreme AI Voice Typer 3.6? We have brought many more new features. (Minor Update)
═══════════════════════════════════════════════════════
✨ NEW FEATURES
───────────────────────────────────────────────────────
1. FIRST-TIME API KEY SETUP.
◦ When you use this extension for the first time, a dialog will guide you to add your API key. You can enter your own Gemini, Groq, or Mistral key, or turn on Use Default API Key to get started right away.

2. USE DEFAULT API KEY.
◦ You can now start typing instantly without adding your own API key. This uses a shared key provided by the developer. Since it is shared among many users, its limit may run out faster, and you may occasionally face issues while typing. Using your own personal API key is recommended for the best experience.

3. HOW TO USE GUIDE.
◦ A new "How To Use" button has been added in General Settings. It opens a simple, easy-to-follow tutorial explaining how to use the app and what each feature does.

4. SMART ENGINE MOVED TO AI SETTINGS.
◦ The Smart Engine (AI Fallback to Raw Text) option has been moved into AI Settings, right next to Auto-Switch Models, along with a short description of what it does.

5. DEVELOPER NOTIFICATIONS.
◦ You can now receive messages and updates directly from the developer inside the app, right on the main Settings screen.
───────────────────────────────────────────────────────
🛠️ IMPROVEMENTS
───────────────────────────────────────────────────────
• Groq and Gemini AI models have been upgraded for better and more reliable typing.

• "Check for Model Update" now fetches more working, active models, and keeps your recommended model unless it truly stops working.

• Fixed several bugs reported by users and improved overall typing stability.
